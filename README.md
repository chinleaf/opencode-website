# Portfolio Website

A one-page personal portfolio with project filtering. Built with only HTML, CSS, and vanilla JavaScript. No dependencies, no CDN. Designed to work at narrow and wide widths and with keyboard navigation. Serve only on localhost.

## Local run instructions

You don't need to install anything. Serve the files from this directory on localhost.

**Option 1: Python (most common)**
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000/` in your browser.

**Option 2: Node.js (if available)**
```bash
npx serve .
```
(or `npx http-server .`)

**Option 3: VS Code Live Server** (extension) - right-click `index.html` and choose "Open with Live Server".

Notes: Do not build, deploy, or install packages. Just serve locally.
